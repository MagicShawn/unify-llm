User guide · 使用指南

Point coding tools at this local gateway. Replace 127.0.0.1 with your LAN IP if the tool runs on another machine · 将编码工具指向本机网关；若工具在其他机器运行，请把 127.0.0.1 换成局域网 IP。

1. Gateway base URLs · 网关地址

Use the API key from the Keys tab (starts with sk-unify-) · 使用「Keys」页签中的密钥。

# OpenAI-compatible · OpenAI 兼容
http://127.0.0.1:8787/v1

# Anthropic-compatible · Anthropic 兼容
http://127.0.0.1:8787

# API key (from Keys tab)
sk-unify-…

2. OpenCode

Example config at ~/.config/opencode/opencode.json · 示例配置路径。

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "local_proxy": {
      "npm": "@ai-sdk/anthropic",
      "name": "Unify Local Gateway",
      "options": {
        "baseURL": "http://127.0.0.1:8787",
        "apiKey": "sk-unify-…"
      },
      "models": {
        "deepseek-flash": { "name": "DeepSeek Flash" },
        "glm-5.3-flash": { "name": "GLM 5.3 Flash" }
      }
    }
  }
}

baseURL is the host root (no /v1) for the Anthropic npm package · Anthropic 包使用主机根路径。

3. Z Code

Claude-Code-like CLI: set Anthropic-compatible env vars · 类 Claude Code 的 CLI：配置 Anthropic 兼容环境变量。

# Windows PowerShell
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:8787"
$env:ANTHROPIC_AUTH_TOKEN = "sk-unify-…"
$env:ANTHROPIC_API_KEY = "sk-unify-…"

# Linux / macOS
export ANTHROPIC_BASE_URL=http://127.0.0.1:8787
export ANTHROPIC_AUTH_TOKEN=sk-unify-…
export ANTHROPIC_API_KEY=sk-unify-…

Optional: ANTHROPIC_API_KEY can match ANTHROPIC_AUTH_TOKEN. Adjust if Z Code docs differ · 若其文档不同请按官方说明调整。

4. Codex / OpenAI Codex CLI

OpenAI-compatible endpoint · 使用 OpenAI 兼容端点。

# Windows PowerShell
$env:OPENAI_BASE_URL = "http://127.0.0.1:8787/v1"
$env:OPENAI_API_KEY = "sk-unify-…"

# Linux / macOS
export OPENAI_BASE_URL=http://127.0.0.1:8787/v1
export OPENAI_API_KEY=sk-unify-…

5. DeepSeek client apps · DeepSeek 客户端

Official app / DSH and similar — only if they allow a custom OpenAI-compatible base URL · 仅当应用支持自定义端点时可用。

Base URL:  http://127.0.0.1:8787/v1
API key:   sk-unify-…
Model:     deepseek-flash
  (or)     deepseek-v4-pro

Works only if the app supports a custom OpenAI-compatible endpoint · 仅在应用允许自定义 OpenAI 兼容端点时有效。

6. Quick checklist · 快速检查

  1. Create a key in the Keys tab · 在「Keys」页签创建密钥
  2. Paste it into your tool (env var or config) · 粘贴到工具的环境变量或配置
  3. Point the tool at http://127.0.0.1:8787/v1 (OpenAI) or host root (Anthropic) · 指向网关地址
  4. Call the API, then watch Usage / Points · 调用后在「Usage / Points」查看消耗
